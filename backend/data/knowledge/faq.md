# 星辰科技常见问题

## 账号相关

### 如何注册账号？
1. 打开星辰科技官网或APP
2. 点击"注册"
3. 输入手机号，获取验证码
4. 设置密码完成注册

### 忘记密码怎么办？
在登录页面点击"忘记密码"，通过手机验证码重置密码。

### 如何修改收货地址？
进入"个人中心" → "地址管理" → 添加或修改地址。下单时也可临时修改。

## 产品使用

### StarPods Pro 耳机如何配对？
1. 打开耳机充电盒，长按触控区3秒进入配对模式
2. 蓝牙指示灯闪烁蓝色
3. 手机蓝牙设置中搜索"StarPods Pro"并连接

### StarWatch X 手表如何同步数据？
1. 下载"星辰健康"APP
2. 打开蓝牙，靠近手表
3. APP自动识别并连接
4. 数据每5分钟自动同步

### 耳机续航不够怎么办？
- 确保固件已更新到最新版本
- 关闭不使用的功能（如通透模式）
- 充电盒可为耳机提供额外3次完整充电
- 总续航可达40小时（关降噪）/ 30小时（开降噪）

## 退换货

### 如何申请退换货？
1. 进入"我的订单"
2. 选择对应订单，点击"申请售后"
3. 选择服务类型（退货/换货/维修）
4. 填写原因并上传照片（如有）
5. 提交后等待审核

### 退换货需要什么条件？
- 7天无理由退货：商品未拆封或保持全新状态
- 15天质量问题换货：提供故障描述或照片
- 需提供购买凭证（订单号）

## 订单相关

### 如何查看订单状态？
进入"我的订单"查看实时状态：待支付 → 已支付 → 已发货 → 运输中 → 已签收

### 可以修改订单吗？
- 未支付：可直接修改商品、数量、地址
- 已支付未发货：联系客服修改地址
- 已发货：不可修改，需等待签收后申请退货

### 如何开发票？
下单时勾选"需要发票"，填写发票信息。也可在订单完成后30天内补开发票。

## 故障排查

### 耳机没有声音
1. 检查耳机是否正确配对
2. 检查音量设置
3. 尝试重置耳机（充电盒中长按触控区10秒）
4. 尝试连接其他设备排除设备问题

### 手表无法充电
1. 检查充电接口是否清洁
2. 确认充电器正常工作
3. 调整手表位置确保磁吸对齐
4. 如仍无法充电，联系售后维修

### APP无法连接设备
1. 确保手机蓝牙已开启
2. 关闭APP后台重新打开
3. 手机蓝牙列表中忽略设备后重新配对
4. 检查APP是否为最新版本
