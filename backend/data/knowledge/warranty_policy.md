# 星辰科技保修政策

## 保修期限

| 产品 | 保修期 | 配件保修 |
|------|-------|---------|
| StarPods Pro 降噪耳机 | 1年 | 6个月 |
| StarWatch X 智能手表 | 2年 | 1年 |
| StarBox 智能音箱 | 1年 | 6个月 |
| 充电器/数据线 | 6个月 | - |

## 保修范围

### 包含
- 非人为因素导致的产品故障
- 正常使用情况下出现的性能问题
- 产品本身的质量缺陷（如电池鼓包、屏幕异常、按键失灵）
- 保修期内的免费维修或更换

### 不包含
- 人为损坏（摔落、进水、自行拆机）
- 意外事故造成的损坏
- 使用非官方配件导致的故障
- 外观磨损和正常老化
- 产品铭牌或序列号被涂改/去除

## 报修流程

1. 准备产品信息和购买凭证（订单号）
2. 联系客服（在线/电话/邮件）描述故障情况
3. 客服评估故障类型，确认保修资格
4. 寄送产品到指定维修中心（运费由公司承担）
5. 维修中心检测并维修，通常3-5个工作日
6. 维修完成寄回产品

## 快速换新

- 购买15天内出现非人为故障，可直接申请换新
- 换新产品享受全新保修期
- 需提供完整包装和配件

## 延保服务

- 官方延保：可额外购买1年延保服务
- StarPods Pro 延保费：¥99/年
- StarWatch X 延保费：¥149/年
- 延保期间享受与原保修相同的服务条款
